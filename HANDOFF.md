## Что это

Сервис на маке: собирает посты из 24 Telegram-каналов, бесплатно фильтрует локально (правила, OCR, whisper, эмбеддинги), ночью разбирает лучшее через `claude -p` в пределах лимита, утром присылает черновики в отдельного бота. По ✅ дописывает в существующую заметку Obsidian или создаёт новую.

- Спека: `docs/specs/2026-10-10-tg-harvester-design.md`

- Git: включён, коммит после каждой задачи (формат в Global Constraints плана)

## Ключевые решения (не пересматривать без Некита)

- Отдельный проект и **отдельный бот**. Telethon на **своей сессии** (не сессия telegram-mcp).
- Промежуточного TG-канала нет, очередь в SQLite. В Telegram ничего не отмечается прочитанным.
- Обход: сначала всё непрочитанное во всех каналах, потом ретро канал за каналом до 2025-10-10. Если в ретро-окне канала больше 5000 постов, окно режется до 2 месяцев.
- Двач: только новые посты, без ретро. Райт = канал «Рома Райт» (@romarayt).
- Только каналы, группы и чаты вне скоупа.
- Ревью обязательно (✅/❌/✏️). Дописывание только в конец под `## Из Telegram`, текст выше не меняется. Откат одной кнопкой, снапшоты 30 дней, аудит по воскресеньям.
- Видео не качается без кнопки «Разобрать». Голосовые расшифровываются все (whisper бесплатный).
- Бюджет: ориентир 10% недельного лимита Pro, на догоне архива до 25%. Точные цифры калибруются на пилоте (задача 11), не выдумывать.
- Новый раздел L2 «Музыка» создаётся в задаче 11 командой `section`.
- Telegram-шаги задачи 11 (бот у @BotFather, `/start`, код входа из чата 777000) Claude делает сам через telegram-mcp, Некит разрешил. Пароль 2FA, если есть, вводит Некит.

- Пороги матчера. Живой замер: близкие по смыслу RU-фразы дают косинус ~0.44, далёкие ~0.06. Дефолт `note_threshold: 0.6` для этой модели, похоже, завышен: почти ничего не станет «дописать». **Главное открытие (не пересматривать молча):** правило «по похожести и длине подписи» почти ничего не решает. По ответам Некита в «Наше тело» полезных ~60-68% в КАЖДОЙ ячейке, в «Эксплойте» 27-42%, потому что вопросы шли только по постам с похожестью 0.7+. Отчёт на отложенных ответах: очередь 3 590 вопросов, правило само отклонит 3. Leave-one-out kNN по эмбеддингам подписи: «Двач» авто-❌ при 0.9 точность ~96% (166 из 636), «Наше тело» авто-✅ при 0.9 лишь 72% (25 постов, 7 ошибок), «Не баг» и «Эксплойт» вообще не различимы. Вывод: ценность видео определяется содержанием ролика, а не подписью.
