## Ключевые решения (не пересматривать без Некита)

- Отдельный проект и **отдельный бот**. Telethon на **своей сессии** (не сессия telegram-mcp).
- Промежуточного TG-канала нет, очередь в SQLite. В Telegram ничего не отмечается прочитанным.
- Обход: сначала всё непрочитанное во всех каналах, потом ретро канал за каналом до 2025-10-10. Если в ретро-окне канала больше 5000 постов, окно режется до 2 месяцев.
- Двач: только новые посты, без ретро. Райт = канал «Рома Райт» (@romarayt).
- Только каналы, группы и чаты вне скоупа.
- Ревью обязательно (✅/❌/✏️). Дописывание только в конец под `## Из Telegram`, текст выше не меняется. Откат одной кнопкой, снапшоты 30 дней, аудит по воскресеньям.
- Видео не качается без кнопки «Разобрать». Голосовые расшифровываются все (whisper бесплатный).
- Бюджет: ориентир 10% недельного лимита Pro, на догоне архива до 25%. Точные цифры калибруются на пилоте (задача 11), не выдумывать.
- Новый раздел L2 «Музыка» создаётся в задаче 11 командой `section`.
- Telegram-шаги задачи 11 (бот у @BotFather, `/start`, код входа из чата 777000) Claude делает сам через telegram-mcp, Некит разрешил. Пароль 2FA, если есть, вводит Некит.

## Открытые вопросы

- Пороги матчера. Живой замер: близкие по смыслу RU-фразы дают косинус ~0.44, далёкие ~0.06. Дефолт `note_threshold: 0.6` для этой модели, похоже, завышен: почти ничего не станет «дописать». Не правлю наугад, это решает калибровка на пилоте (задача 11, `calibrate`). Если калибровки ещё нет, а пороги нужны раньше, ориентир ~0.45 / 0.35.
- Финальное ревью ветки свежим ревьюером ещё не делалось (по плану после задачи 11, Review Focus в плане).
