# TG Harvester: дизайн

Дата: 2026-10-10. Статус: ждёт вычитки Некита.

## 1. Цель

Сервис на маке, который круглосуточно собирает посты из выбранных Telegram-каналов, локально (без токенов) отсеивает мусор и находит посты по темам vault, ночью прогоняет отобранное через `claude -p` и предлагает Некиту в отдельном боте черновики: дописать в существующую заметку Obsidian или создать новую. После одобрения пишет в vault.

Vault для Некита это список «изучить/использовать позже» по темам. Поэтому ценность поста = практическая польза потом: гайд, промпт, инструмент, схема, цифры, рекомендация книги/курса. Новости не берём.

Критерии успеха:
- сбор и фильтр работают без участия Некита и без расхода токенов;
- расход Claude укладывается в бюджет: ориентир 10% недельного лимита Pro в живом режиме, до 25% в фазе ретро (калибруется на пилоте, см. §8);
- в vault попадает только одобренное Некитом, существующий текст заметок не меняется никогда;
- любая запись откатывается одной кнопкой;
- ни один пост не теряется молча: каждый в итоге в статусе `written`, `rejected`, `filtered` или `error` с причиной.

## 4. Архитектура

```
tg-harvester/
├─ harvester/
│  ├─ collector.py   Telethon: новые посты, ретро, живой режим → SQLite
│  ├─ enricher.py    OCR картинок, whisper голосовых, удаление медиа
│  ├─ matcher.py     эмбеддинги: score поста + целевая заметка/раздел
│  ├─ brain.py       ночные батчи claude -p → черновики, лимит вызовов
│  ├─ bot.py         отдельный бот: карточки, видео-запросы, отчёты, откат
│  ├─ writer.py      запись в vault, MOC, холст, снапшоты
│  ├─ auditor.py     еженедельная проверка добавленного
│  ├─ db.py          SQLite, статусы
│  └─ vault/         перенесено из idea-bot (fs, notes, canvas, index)
├─ config/channels.yaml, config/settings.yaml
└─ scripts/setup.sh  установка launchd-агентов
```

Модули общаются только через статус поста в SQLite:

```
new → enriched → candidate ─┬→ drafted → approved → written
            │               │              └→ rejected
            └→ filtered     └→ (ждёт следующей ночи, если лимит кончился)
любой шаг → error (с причиной, ретрай на следующем прогоне, максимум 3)
```

Процессы launchd:
- `harvester-live`: collector + enricher + matcher + bot, постоянно;
- `harvester-night`: brain, ежедневно 03:00;
- `harvester-audit`: auditor, воскресенье 04:00.

Код vault берётся из idea-bot копией (а не общим пакетом), чтобы правки в одном проекте не ломали другой.

## 5. Сбор

**Фаза 1, новое.** Канал за каналом: все посты новее отметки «прочитано» самого Telegram на момент первого запуска (берётся один раз при инициализации и дальше не используется). Когда канал дочитан, переходим к следующему.

**Фаза 2, ретро.** Когда новое дочитано во всех каналах: канал за каналом от самого старого собранного поста назад до `2025-10-10`. Перед каждым каналом preflight: сколько постов в окне (по разнице message id на границах). Если больше `retro_cap` (по умолчанию 5000), граница сдвигается на 2 месяца назад от сегодня. Решение пишется в отчёт.

**Живой режим.** С момента первого запуска события о новых постах во всех каналах сразу пишутся в SQLite параллельно с фазами 1 и 2.

Альбомы (`grouped_id`) склеиваются в один пост. Пауза между запросами, FloodWait обрабатывается сном на указанное время. Прогресс по каждому каналу сохраняется, рестарт продолжает с места.

## 6. Фильтр (0 токенов)

1. **Правила:** отсеиваются реклама (`erid`, «реклама», «розыгрыш», «промокод» и список в settings), пустые посты, посты короче `min_chars` без медиа с текстом.
2. **Обогащение:** картинки (до 4 на пост) скачиваются во временную папку, OCR через macOS Vision (`ocrmac`, языки ru+en). Голосовые и аудио расшифровываются `mlx_whisper`. Текст склеивается с подписью. Медиа удаляются сразу после.
3. **Совпадение с vault:** локальная модель эмбеддингов (multilingual, ~0.5 GB, влезает в 8 GB RAM). Индекс заметок vault (заголовок + первые ~1000 символов) пересчитывается для изменённых файлов раз в сутки. Для поста:
   - похож на заметку (score ≥ `note_threshold`): кандидат, режим «дописать», целевая заметка;
   - похож на раздел L2 (средний score по разделу ≥ `section_threshold`): кандидат, режим «новая заметка»;
   - ни то ни другое: не кандидат, но лучшие из них по «полезности» (длина, ссылки, списки, слова «гайд/промпт/инструмент/схема») идут в квоту `explore_quota` за ночь: кандидаты на расширение тем.
4. **Видео:** не качаются. Если подпись/текст поста стал кандидатом, бот присылает карточку «🎬 Анализировать / ❌». По «Анализировать»: скачать, ffmpeg вытаскивает аудио + 3 кадра, whisper + OCR кадров, пост возвращается в `enriched`, видео удаляется.

Пороги подбираются на пилоте по выборке, которую Некит размечает в боте (см. §8).

## 7. Мозг (ночь)

- Кандидаты сортируются по score. Ретро и живой режим идут вместе, живые первыми.
- Батч ~20 постов в один `claude -p`. В промпте: текст постов, для каждого 3 ближайшие заметки (заголовок + кусок) и список разделов L2, цели Некита из `Мои цели.md` (кратко, кэшируется).
- Ответ JSON на каждый пост: `valuable` (bool + причина), `mode` (`append` / `new` / `skip`), `target` (путь заметки или раздел), `content` (то, что пишется: суть, промпт дословно, ссылки), `title` для новой. Невалидный JSON: один ретрай, потом `error`.
- Картинка уходит в Claude, только если пост прошёл в батч и OCR пустой, а картинка явно несёт смысл (схема, скрин интерфейса). Лимит картинок за ночь в settings.
- **Бюджет:** `max_calls_per_night` (база) и `retro_multiplier` (2.5, пока фаза ретро не закончена). Когда лимит исчерпан, остальное ждёт следующей ночи. Счётчик вызовов в отчёте.

## 8. Пилот и калибровка

Первые 2 ночи (после того как Некит одобрит план и всё установлено):
1. Бот присылает 50 случайных постов, прошедших правила, кнопки «полезно / мусор». По разметке подбираются пороги `note_threshold`, `section_threshold`.
2. Ночь с `max_calls_per_night = 5`. Некит смотрит в claude.ai, сколько % недельного лимита ушло. Исходя из этого выставляется база под 10% / 25%.

## 9. Ревью и запись

Утром бот присылает карточки (по одной на черновик, пачкой не больше `cards_per_day`, остальные в очереди):

```
📌 Не баг, а фича · 12.09.2026
→ дописать в [[Промпты для кодинга]]
<что будет записано>
[ ✅ ] [ ❌ ] [ ✏️ другая заметка ] [ 🔗 пост ]
```

- ✏️ показывает 5 ближайших заметок и вариант «новая заметка в разделе X».
- **Дописывание:** в конец заметки, под заголовком `## Из Telegram` (создаётся, если нет). Формат строки: `- <суть> ([пост](https://t.me/c/...), 2026-10-10)`. Выше этого заголовка файл не меняется побайтно.
- **Новая заметка:** atomic-формат, frontmatter (`source`, `date`, `tags`), wikilinks на 1-3 ближайшие заметки, строка в MOC раздела, file-нода в холсте раздела. Формат как в idea-bot и `Правила оформления холстов.md`.
- Картинка-первоисточник сохраняется в vault, только если Claude отметил её как несущую смысл.
- **Снапшот:** перед каждой записью затронутые файлы копируются в `data/snapshots/<дата>/`. Хранятся 30 дней.
- Каждый записанный блок получает id в SQLite (файл, байтовый диапазон, хэш). Кнопка «↩️ Откатить» под подтверждением удаляет ровно этот блок, если файл после него не менялся в этом месте; иначе бот говорит, что откатить автоматически нельзя, и даёт путь к снапшоту.

## 10. Аудит (воскресенье)

`claude -p` получает все блоки, записанные за неделю, вместе с заметками, куда они легли. Проверяет: блок по теме заметки, нет дубля с уже имеющимся, нет обрывков. Бот присылает отчёт: «ок N, сомнительные M» и карточку на каждый сомнительный с «↩️ Откатить / оставить». Аудит тоже считается в бюджет.

## 11. Отчёты и сбои

Утренний отчёт в боте: собрано, отфильтровано правилами/матчером, черновиков, вызовов Claude N из лимита, ошибки, прогресс по каналам (фаза, дата, до которой дошли).

- Перед скачиванием медиа: `df -h ~`. Меньше 10 GB: медиа пропускаются (текст обрабатывается), алерт в бот.
- `claude -p` недоступен (нет бинаря, лимит подписки): ночь прерывается, посты остаются `candidate`, алерт.
- Telethon потерял сессию: алерт в бот с инструкцией перелогина.
- Падение процесса: launchd перезапускает, работа продолжается по статусам.

## 12. Тесты

pytest, как в idea-bot: vault на `tmp_path`, Telethon и `claude -p` замоканы, SQLite в памяти. Отдельно тесты на: склейку альбомов, preflight ретро, байтовую неизменность заметки выше `## Из Telegram`, откат блока, лимит вызовов. Живой vault трогается только на финальном прогоне с Некитом.

## 13. Вне скоупа

- Группы/чаты (только каналы).
- Мультиюзерность, продуктизация.
- Автоматическая запись без ревью (вернуться после 2 недель работы, если черновики стабильно хорошие).
- Анализ видео без запроса.
