# Перенос tg-harvester на сервер (дизайн, 07.11.2026)

Статус: одобрен Некитом 07.11.2026. Шаги 1-4 готовы (сервер, зеркало, пакеты, OCR), юниты и FreeLLMAPI на сервере подготовлены, не включены. Дальше: сухой прогон и переключение по `tools/server-trial/harvester-cutover.md`. Дополнение к дизайну: FreeLLMAPI тоже переезжает на сервер (зависимость `router_fallback`), часовой пояс сервера Asia/Ho_Chi_Minh.

## Решения Некита
- Сервер: пробный Contabo (24 ГБ, 8 vCPU, Ubuntu). Telethon-сессию создать заново на сервере, не копировать.
- Vault: **копия vault на сервере (только чтение) + пакеты записи**. Писатель в настоящий vault один: ноут. Запись с задержкой в минуты допустима ("1 - норм").
- OCR на сервере: Tesseract rus+eng (сравнить с ocrmac на 20 картинках до переключения).
- Whisper уже заменён на Groq, `claude -p` уже идёт через `tools/claude-remote` (но на сервере вызывается напрямую, обёртка не нужна).
- Правила «не пропускать ночь» относились к Mac; на сервере проверки `foreign_whisper` и `mem_free` не нужны.
- Сервер сам к ноуту НЕ подключается: все копирования инициирует ноут по SSH.

## Схема
```
 СЕРВЕР (24/7)                                   НОУТ (по расписанию)
 ------------------------------                  ---------------------------
 collector + live (Telethon)                     applier (launchd, раз в 5 мин)
 filter, matcher (fastembed)                      1. rsync outbox/ с сервера
 brain (claude -p, Groq, tesseract)               2. для каждого пакета:
 bot (Telegram) ---- ✅ ----> outbox/*.json          вставить draft+post в
 ~/vault-mirror/ (read-only)                         data/harvester.db,
                                                     запустить Writer.apply()
 acks/ <------------------------------------------  3. положить ack в acks/
 ack-reader: draft written/failed                 4. rsync vault (.md,.canvas)
   -> бот пишет "записано / ошибка"                  на сервер (зеркало)
```
Главная идея: **Writer и журнал блоков отката не меняются**, остаются на ноуте. Applier ставит в локальную `harvester.db` строки draft и post из пакета и вызывает тот же `Writer.apply(did)`. Откат (кнопка в боте) идёт тем же путём пакетом `rollback`.

## Пакет
`outbox/<id>-<kind>.json`: `kind` = `apply | rollback`; для `apply` копия строк draft и post (target, mode, content, title, keep_image, top3, chat_id, msg_id, date, images) + файлы картинок рядом (`outbox/<id>/img*`); для `rollback` номер блока. Ack: `{id, ok, block_id, error}`.

## Данные и миграция (что уже есть)
- `data/harvester.db` (посты, драфты, labels, kv, **журнал блоков**): остаётся на ноуте как база applier; **копия** уезжает на сервер как стартовая база бота. Прежние записи откатываются через пакет `rollback`, журнал у ноута.
- Эмбеддинги (кэш), конфиги, `config/channels.yaml`: копия на сервер.
- Снапшоты `data/snapshots/`: остаются на ноуте (их делает Writer).
- Telethon-сессия: новая, коды вводит Некит.
- BOT_TOKEN: один бот в одном месте. Порядок: стоп на ноуте -> старт на сервере.

## Шаги
1. Сервер: uv, зависимости, `tesseract-ocr-rus`, systemd-юниты с `MemoryMax` (бот, ночной прогон, аудит), таймеры вместо launchd.
2. Зеркало vault: скрипт на ноуте (rsync по SSH, только `.md`, `.canvas`, без `.obsidian`, без вложений), в launchd раз в 5 мин и после каждого применённого пакета.
3. Код: режим `apply_mode=packet` (PacketWriter на сервере), `harvester applier` (ноут), ack-reader (сервер). Тесты: пакет -> Writer -> ack на фикстурах vault, повтор пакета не пишет дважды, откат, падение посреди.
4. OCR: замена `ocr_image` для Linux, замер на 20 картинках против ocrmac.
5. Сухой прогон: сервер собирает и делает драфты, бот шлёт их, applier пишет в **копию vault** (не в настоящий). Сверка.
6. Переключение: стоп бота и ночных задач на ноуте (`bootout` + `disable`, plist в `tools/server-trial/`), убрать из `resource-guard`/`boot-stagger`, старт на сервере, applier на настоящий vault.
7. Через 2 ночи: замеры, правка лимитов, решение по зеркалу.

## Критерии готовности
- Драфт с ✅ превращается в запись в настоящем vault и в ack «записано» в боте; то же для нового файла, дописи и отката.
- Повторная доставка пакета не создаёт дубль.
- Ноут спит: пакеты ждут; после пробуждения применяются по порядку.
- Ночной прогон 03:00 проходит на сервере; в логе нет пропусков из-за памяти.
- Зеркало на сервере не старше 10 минут, когда ноут онлайн.

## Риски
- Конфликт при правке заметки Некитом в Obsidian между зеркалом и применением: допись идёт по текущему файлу на ноуте (как сейчас), зеркало лишь чуть устарело.
- Ноут выключен днём: ✅ подтверждается позже; бот сразу пишет «в очереди».
- Tesseract хуже Apple Vision: решаем по замеру.
- `live.py` (живая лента) на сервере: проверить, что не зависит от Mac.
- Пакет с картинкой теряется при падении сервера: пакет пишется атомарно (tmp + rename).
