# План: вопросы по темам вместо вопросов по каждому видео

Дата: 2026-10-24. Решения Некита: тема целиком (одна карточка), сначала показывать список, потом режим «без списка»; немые ролики без речи и текста помечаются «без описания» (вариант А), кадры не смотрим.

## Поток

```
очередь видео ─► метаданные файла (document id) ─► тема (роутер) ─► карточка темы
                                                                      │
        ┌────────────────────────────┬───────────────────────────────┤
 [🔬 Проверить тему]        [👀 Показать 3]                  [🚫 Тему не надо]
        │                    3 обычные карточки               все видео темы закрыты
  ночью: громкость → Whisper, кадры → OCR (по одному на уникальный файл)
        │
  роутер склеивает: уникальные упражнения/советы, повторы, «без описания»
        │
  итоговая карточка со списком ─► [📝 Записать в заметку] ─► обычный черновик (✅/✏️ как всегда)
```

Настройки: `video_by_topic`, `topic_cards_per_day` (10), `topic_min_size` (2), `topic_review: list|auto`, `topic_check_per_night` (30 видео), окно проверки 01-07, порог тишины -60 dB.

## Пачки (TDD, коммит после каждой)

1. БД, метаданные файла (`document.id`, размер, длительность), разметка тем через роутер, команда `harvester topics tag`.
2. Карточка темы и кнопки (проверить / показать 3 / не надо), исключение тематических постов из поштучных вопросов.
3. Ночная проверка темы (скачать, громкость, Whisper, OCR), склейка роутером, итоговая карточка, «Записать» как черновик, режим `auto`.
4. Встраивание в live, запуск на реальных данных, разметка очереди, проверка карточек с Некитом.

## Риски

- Одна Telethon-сессия: все обращения к Telegram только из live-процесса, второй клиент не создаём.
- Роутер бесплатный: сбой не штрафует посты, повторяем позже.
- Тема может быть слишком широкой («питание»): карточка показывает примеры подписей, Некит решает по ним.
